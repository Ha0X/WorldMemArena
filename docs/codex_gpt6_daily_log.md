### 关键判断与汇报口径

- 工作贡献是仓库评测链路的适配、故障定位、隔离和可审计运行；当前没有提出新的记忆算法。
- 评测输入是已记录的 GUI 轨迹，输出是 checkpoint QA；没有重新执行桌面 GUI 任务。
- 每个样本一个持续 thread，顺序接收 session，在 checkpoint 回答问题；历史问题和模型答案保留，gold 只供外部评分使用。
- 正式样本没有主动调用工具，因此结果主要体现持续上下文表现，不能据此证明自主磁盘记忆策略有效。
- 当前是三个样本的同指标参考；数据范围、backbone、judge 及作者精确 runtime 存在差异，不能宣称严格同条件复现或胜过论文。Judge 请求 `gpt-5.4-mini`，provider 返回标识为 `gpt-5.6-terra`，该差异已记录。
- 两例 judge 抽查提示所选 gold/evidence 可能漏掉轨迹细节；保留原评分，不据两例修改整体结论。
