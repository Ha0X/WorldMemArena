## 目前困难与证据

1. **历史交接：** Codex 分支每次独立 exec，没有 resume 或显式 memory 交接；checkpoint 仅含问题。S08 原始回复能复述 Purchased，后续 QA 的实际输入却没有它。共享 cwd/CODEX_HOME 和大 context 上限不会自动传递历史；仅关闭 ephemeral 也不自动恢复线程。
2. **工具执行：** workspace-write 沙箱下 `pwd` 返回 `bwrap: Failed to make / slave: Permission denied`。本轮没有取消沙箱或扩大权限绕过；是否存在可用的隔离执行环境仍需检查。
3. **工具审计盲区：** 这版 CLI JSONL 不完整暴露 custom tool 调用，顶层 tools 字段也不能单独代表工具可用性。之前“无工具事件=完全无工具使用”的结论已撤回。后续必须记录实际工具请求/返回并做内容核查。
4. **论文实现细节未齐：** adapter 注释描述 persistent session，Codex 实现却是独立 exec；README 仅给安装/认证步骤。不能在证据不足时把 resume、拼接历史或固定 JSON memory 任一种方案称为论文原版。

judge 请求 gpt-5.4-mini，原生评分的返回标识均为 gpt-5.6-terra；用户已接受这项差异不阻碍推进。继续记录实际标识，它不是此次全量拒答的原因。“更强 judge”不保证更高分。
