## 五项 QA 指标

依据本地论文 Table 3 和 Appendix B.1/B.3；本地沿用仓库 evaluator，并采用每样本内汇总、再跨样本平均。
QA-C 越高越好；QA-H、QA-O 越低越好；F1、BLEU-1 越高越好。后两项衡量答案文本重合，不能替代正确性判断。

| 方法 / 范围 | QA-C ↑ | QA-H ↓ | QA-O ↓ | F1 ↑ | BLEU-1 ↑ |
|---|---:|---:|---:|---:|---:|
| 论文 Codex–GPT-5.4-nano（Table 3 汇总） | 53.62 | 20.76 | 25.62 | 32.56 | 10.12 |
| 本地 N：GPT-6-astra，3 个 GUI 样本 | 18.62 | 2.48 | 78.90 | 9.57 | 3.53 |
| 本地 B：GPT-6-astra，3 个 GUI 样本 | 50.92 | 28.62 | 20.46 | 25.51 | 10.76 |

| 本地减去论文 | Δ QA-C | Δ QA-H | Δ QA-O | Δ F1 | Δ BLEU-1 |
|---|---:|---:|---:|---:|---:|

B 相对论文参考行：正确率低 2.70 个百分点、幻觉率高 7.86 个百分点、遗漏率低 5.16 个百分点；F1 低 7.05 个百分点，BLEU-1 高 0.64 个百分点。不能由其中单项差值推断系统优劣。

## 可比范围和限制

- 指标定义、分值单位与样本宏平均方式对齐；无需重跑模型即可计算本表。
- 本地为三个 GUI 样本，每协议 161 QA；论文 Table 3 为更广范围的汇总，没有获得这三个样本的官方逐题预测或单样本成绩。数据范围尚不匹配。
- 论文主结果说明使用 GPT-5.4-mini judge；上表历史 N/B 探索使用 gpt-6-astra judge。当前正式运行改为请求 gpt-5.4-mini、provider 返回 gpt-5.6-terra，不能与历史 N/B 的 judge 设置混为一谈。F1/BLEU-1 为程序计算，但仍受样本与答案风格影响。
- 论文 Table 3 标记 Codex–GPT-5.4-nano，正文描述 GPT-5.4；这里保留表格名称，不擅自推断作者实际模型。
- N 是原生 prompt/流程的受控运行；B 是 fresh context + memory-only 工具。两组都 fresh，都不 resume。N/B 同时改变 prompt、记忆工具和显式截图输入。
- 三个样本各一次有效运行，不能提供跨任务稳健性或多随机种子的显著性结论。

## 其他论文指标为何不填

论文 Table 2 的 memory Recall、Correctness、Hallucination、Irrelevance、Update Handling、Interference Rejection，以及 retrieval coverage / ranking，需要逐 session 记忆项和检索记录与 gold 对齐。本次使用 harness answer-only 评分，没有计算这些生命周期指标；它们应记为未评估，不能填 0，也不能用 QA-C 替代。B 有 JSON 快照可供后续单独分析，但必须先定义和验证映射协议。
